# Arquivos-fonte

Este projeto foi construído a partir de dois recortes dos Microdados do ENEM 2021 para a Bahia:

- `dados_enem_2021_BA.csv`
- `dados_enem_2021_BA_questoes_socieconomicas.csv`

Os arquivos individuais não são versionados aqui porque a base principal ultrapassa 100 MB.

Para reproduzir a preparação completa, coloque os dois arquivos nesta pasta mantendo esses nomes.

O dicionário de variáveis usado na interpretação foi `Dicion_rio_Microdados_Enem_2021.xlsx`.
